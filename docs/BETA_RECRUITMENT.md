### Importer le suivi dans Google Sheets (2 min)

1. Ouvrir [Google Sheets](https://sheets.google.com) → **Fichier → Importer**
2. Téléverser `docs/beta-tracking.csv` → **Remplacer la feuille**
3. **Données → Créer un filtre** sur la ligne 1
4. (Optionnel) Mise en forme conditionnelle sur colonne **Statut** :
   - `Prospect` → gris · `Contacté` → jaune · `Inscrit` → bleu · `Annonce live` → vert
5. Partager le sheet avec vous-même (mobile) pour cocher en déplacement
